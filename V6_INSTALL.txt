Deepstrike Alert Archive v6 update

What changes:
- Parent region always lights when any city/municipality inside it has an active alert.
- OpenFreeMap city/town/village features receive dim lamp dots across the map.
- Official local reports pulse amber for 45 minutes around their timestamp; they are NOT treated as formal alerts.
- High-resolution official source registry expanded from 9 to 18 sources, including Moscow, Moscow Oblast, Bryansk, Yaroslavl, Nizhny Novgorod, Ryazan, Vladimir, Oryol and Kaluga.
- GeoNames cities5000 catalog is generated by GitHub Actions and used by the collector to resolve many cities without hard-coding them in sources.json.
- MChS RSS parsing can also use the generated city catalog when a local place is named.
- More alert-clear wording variants are recognized, including Nizhny Novgorod's "Отмена сигнала ОПАСНОСТЬ АТАКИ БПЛА".
- Local count parsing recognizes phrases such as "сбили и подавили 249 БПЛА" and approximate/minimum qualifiers.
- Telegram pagination limit increased for high-volume channels.

Install:
1) Extract this update directly over your existing deepstrike-github-pages folder.
2) PowerShell:
   cd "C:\Users\20060\Downloads\deepstrike-github-pages"
   git status
   git add .
   git commit -m "v6 hierarchical alerts city catalog and source expansion"
   git pull --rebase origin main
   git push
3) Wait for Deploy GitHub Pages.
4) Run Actions -> Update delayed archive data manually once.
   This first v6 run also builds data/cities.json from GeoNames and commits it.
5) Wait for the bot commit and the following Pages redeploy, then Ctrl+F5.

The update ZIP intentionally does NOT contain data/events.json or data/russia.geojson.
